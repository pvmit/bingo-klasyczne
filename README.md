# Bingo klasyczne

Osobna gra: **własna plansza**, cele odznacza **admin**. Sync jak Conquest (GitHub Pages + Supabase). **Bez kodu pokoju.**

To nie jest [pvmit/bingo](https://github.com/pvmit/bingo) (wersja 2 graczy).

## Jak grac

Wszyscy otwierają: [pvmit.github.io/bingo-klasyczne](https://pvmit.github.io/bingo-klasyczne/)

1. Laptop: **ADMINISTRATOR** → **Nowa gra**.
2. Telefony: ten sam link → pseudonim → **GRACZ**.
3. Laptop możesz zamknąć.

## Baza (raz)

W SQL Editorze Supabase uruchom [`supabase/schema.sql`](supabase/schema.sql). Adres i klucz: [`config.json`](config.json).
